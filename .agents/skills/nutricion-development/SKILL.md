---
name: nutricion-development
description: Mantener y validar la aplicación personal de nutrición en español para GitHub Pages.
---
Utiliza el checkout existente; no crees worktrees salvo petición explícita. La app es estática, sin secretos ni backend. Conserva compatibilidad con rutas relativas de GitHub Pages. Ejecuta npm test y node --check app.js. Arranca con npm start y comprueba la página y sus módulos mediante HTTP. Verifica manualmente altas, borrados, persistencia tras recarga y exportación/importación cuando haya navegador disponible. No anuncies pruebas de interfaz no ejecutadas. Todos los textos deben estar en español. Evita presentar referencias alimentarias orientativas como datos certificados. Conserva procedencia y unidades por 100 g. Nunca cambies el presupuesto de calorías con estimaciones del ejercicio sin una decisión explícita del usuario. Valida copias importadas y escapa texto de usuario y APIs al renderizar. No publiques registros personales en Git ni incluyas datos personales en la web estática.
